# WriteOnce

WriteOnce is an open source document-templating application that helps **consultants, agencies, and freelancers** generate professional client documents — proposals, contracts, statements of work, and invoices — in minutes.

Instead of copy-pasting old documents and risking errors, WriteOnce lets you:

1. **Create a template** from an existing document.
2. **Highlight variables** (like client name, fees, dates, deliverables).
3. **Save the template** for reuse.
4. **Fill in the variables** for a new client and export a polished PDF.

Build a document once, reuse it forever. WriteOnce reduces busywork, prevents embarrassing mistakes, and keeps client deliverables consistent and professional.

## Available Scripts

In the root directory, you can run:

### `yarn start`

Runs the app in development mode.
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### `yarn add {package-name}`

Installs a new package using Yarn.

### `yarn remove {package-name}`

Removes a package using Yarn.

### `yarn test`

Launches the test runner in watch mode.
See [running tests](https://facebook.github.io/create-react-app/docs/running-tests) for more info.

### `yarn build`

Builds the app for production to the `build` folder.
It bundles React in production mode and optimizes for performance.
The build is minified and filenames include hashes.
Your app is ready to be deployed!

See the section about [deployment](https://facebook.github.io/create-react-app/docs/deployment) for more information.
